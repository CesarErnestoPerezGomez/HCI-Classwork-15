# HCI-Classwork-15

This repository contains the Unity project "Classwork 15". The game includes physics mechanics, coin collection, and a victory Canvas.

## Prerequisites
* **Unity Version:** 6000.5.7f1.
* **Platform:** Windows 64-bit.

## Installation and Execution

1. **Download the repository:**
   * Navigate to the repository URL: `https://github.com/CesarErnestoPerezGomez/HCI-Classwork-15`.
   * Click the green `<> Code` button and select **Download ZIP**.
   * Alternatively, you can clone the project by opening Git Bash and running: `git clone https://github.com/CesarErnestoPerezGomez/HCI-Classwork-15.git`

2. **Open in Unity Hub:**
   * Extract the folder if you downloaded the ZIP file.
   * Open Unity Hub, go to the projects section, and click the **Add** (or **Open**) button.
   * Select the root folder of the project you just downloaded.

3. **Verify the version:**
   * Make sure the "Editor version" column correctly assigns version `6000.5.7f1` to the project.
   * If you don't have that specific version installed, Unity Hub will show a warning and give you the option to install it.

4. **Test the game:**
   * Click on the project name in Unity Hub to open the editor.
   * In the "Project" window (at the bottom), go to the `Assets` folder, find your main scene, and double-click to open it.
   * Press the **Play** button at the top center of the screen to start playing.

## Player Controls
* **W, A, S, D:** Move the sphere.
* **Space:** Jump.
